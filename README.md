# ExCord

**언어: [한국어](README.md) | [English](README.en.md)**

디스코드(Discord)를 하면서 아쉬웠던 기능들을 하나씩 모아서 만든 개인용 Windows 상주 프로그램입니다. 트레이(작업표시줄 구석) 아이콘 하나로 조용히 떠 있다가, 필요할 때 텍스트를 음성으로 읽어주거나(TTS), 화면 위에 움직이는 캐릭터/짤을 띄워주는(GifTalk) 기능을 켜고 끌 수 있습니다.

---

## 제작 배경

지인들과 디스코드 통화를 하다 보면 "타이핑한 걸 그대로 말로 읽어주면 편할 텐데" 싶은 순간이 종종 있었습니다. 마이크 상태가 안 좋을 때, 목이 안 좋을 때, 혹은 그냥 장난삼아 봇처럼 말하고 싶을 때 등 이유는 다양했습니다. 시중의 TTS 프로그램들은 대부분 디스코드 전용이 아니거나 설정이 번거로워서, 핫키 한 번으로 바로 띄우고 바로 말할 수 있는 가벼운 도구를 직접 만들게 되었습니다. 여기에 화면 위에 반응형 캐릭터(GIF)를 띄우는 "GifTalk" 기능도 함께 얹어서, 통화 분위기를 조금 더 재미있게 만들 수 있도록 확장했습니다.

하나의 큰 기능에 집중하기보다는, 디스코드를 쓰면서 아쉬웠던 부분이 생길 때마다 계속 기능을 붙여나가는 개인 툴킷 성격의 프로젝트입니다.

---

## 주요 기능 요약

| 기능 | 설명 |
|---|---|
| **TTS (Text-to-Speech)** | 전역 단축키로 작은 입력창을 띄우고, 입력한 텍스트를 음성으로 변환해 가상 오디오 장치로 재생합니다. 디스코드가 이 가상 장치를 마이크로 인식하면, 상대방에게는 내가 "말하는" 것처럼 들립니다. |
| **GifTalk** | 원하는 GIF·이미지·웹페이지 URL을 화면 위에 항상 위(always-on-top) 오버레이로 띄웁니다. 마우스를 올리면 자동으로 옅어지고 클릭도 통과시켜서, 다른 작업을 방해하지 않습니다. |
| **트레이 상주** | 메인 창 없이 작업표시줄 구석 아이콘으로만 존재하며, 더블클릭하면 설정 창이 열립니다. |

## 상세 기능 설명

### 1. General 탭 (전역 설정)

- **Start with Windows**: 켜면 윈도우 시작 시 ExCord가 자동으로 함께 실행됩니다. (레지스트리의 `HKCU\...\Run` 항목을 이용하며, 관리자 권한이 필요 없습니다.)
- **Text-to-Speech**: TTS 기능 전체를 켜고 끕니다. 꺼두면 전역 단축키가 비활성화되고, 설정 창의 TTS 탭도 흐리게 비활성화됩니다.
- **GifTalk**: GifTalk 기능 전체를 켜고 끕니다. 꺼두면 화면 위 오버레이 창이 사라지고, 설정 창의 GifTalk 탭도 흐리게 비활성화됩니다.


### 2. TTS 탭

#### 2-1. 전역 핫키 (Global Hotkey)

- `Ctrl` / `Alt` / `Shift` 체크박스와 키 선택 드롭다운을 조합해서 원하는 단축키를 만들 수 있습니다. 기본값은 **`Ctrl + Alt + T`** 입니다.
- 이 단축키를 누르면 어떤 프로그램을 쓰고 있든(디스코드, 게임, 브라우저 등) 화면 하단 중앙에 디스코드 스타일의 작은 입력창이 나타납니다.
- 입력창 사용법:
  - **Enter**: 입력한 텍스트를 즉시 음성으로 변환해서 재생하고 창을 닫습니다.
  - **Esc**: 아무것도 하지 않고 창을 닫습니다.
  - 입력창은 포커스를 잃으면(다른 창을 클릭하면) 자동으로 숨겨집니다.
  - 이미 말하는 중에 새 문장을 또 입력해서 보내면, 이전 재생은 즉시 중단되고 새 문장이 재생됩니다.

#### 2-2. TTS Voice (음성 선택)

- 드롭다운에 두 종류의 음성이 함께 나열됩니다.
  1. **Windows 최신 음성 (OneCore)**: `설정 → 접근성 → 내레이터 → 음성 추가`에서 추가로 설치할 수 있는 자연스러운 음성들입니다.
  2. **SAPI5 음성**: 예전부터 Windows에 내장돼 있던 음성 엔진(Microsoft David, Zira 등)이나, 별도로 설치한 SAPI5 음성 팩입니다.
- 목록은 언어 → 이름 순으로 정렬됩니다.
- **더 다양한 목소리를 쓰고 싶다면**: Windows 설정의 "음성 추가"에서 원하는 언어의 음성을 내려받은 뒤 ExCord를 다시 열면 목록에 자동으로 나타납니다.
- 만약 선택했던 음성이 어떤 이유로 사라지면(제거 등), 프로그램이 자동으로 비슷한 언어의 다른 음성으로 대체하고 트레이 알림으로 알려줍니다.

#### 2-3. Virtual Output Device (가상 출력 장치)

- TTS로 변환된 음성은 여기서 고른 오디오 출력 장치로 재생됩니다. **디스코드에서 상대방이 이 소리를 듣게 하려면, 디스코드의 마이크 입력 장치를 이 가상 장치와 동일하게 맞춰줘야 합니다.**
- 일반 스피커나 헤드폰을 그대로 선택하면 나만 듣고 상대방에게는 전달되지 않습니다. 그래서 **"가상 오디오 케이블(Virtual Audio Cable)"** 프로그램이 별도로 필요합니다. 대표적으로 무료인 **[VB-CABLE](https://vb-audio.com/Cable/)**가 있으며, 기본값도 `VB-Cable`로 되어 있습니다.
- 설정 순서 요약:
  1. VB-CABLE(또는 StealSeries GG 등 다른 가상 오디오 케이블)을 설치하고 컴퓨터를 재부팅합니다.
  2. ExCord 설정의 Virtual Output Device 드롭다운에서 새로 생긴 가상 입력 장치(`CABLE Input`)를 선택합니다.
  3. 디스코드 설정 → 음성 및 비디오 → 입력 장치를 동일한 가상 입력 장치 쪽(`CABLE Input`)으로 맞춥니다.
- 컴퓨터에 연결된 오디오 장치 목록을 자동으로 스캔해서 보여주며, `VB`가 이름에 들어간 장치를 우선적으로 기본 선택합니다.

#### 2-4. Output Volume (출력 볼륨)

- 0~100% 슬라이더로 TTS 음성 자체의 출력 볼륨을 조절합니다.

#### 2-5. Play monitor sound on default speaker (모니터링)

- 체크하면 가상 장치뿐 아니라 **내 컴퓨터의 기본 스피커/헤드폰으로도 동시에** 같은 음성이 재생됩니다. 즉, 내가 지금 무슨 말을 "TTS로 내보내고 있는지" 직접 들으면서 확인할 수 있습니다. 끄면 나에게는 들리지 않고 가상 장치로만 나갑니다.


### 3. GifTalk 탭

#### 3-1. GIF URL

- 텍스트 박스에 웹 주소(GIF 직링크, 이미지, 또는 일반 웹페이지 URL 모두 가능)를 입력하고 **Apply** 버튼을 누르면, 화면 위 오버레이 창이 그 주소를 즉시 불러옵니다.
- 내부적으로 Microsoft Edge WebView2(크로미움 기반 브라우저 엔진)를 사용하기 때문에, 움직이는 GIF는 물론 간단한 HTML 페이지나 웹 위젯도 띄울 수 있습니다.
- 배경이 투명한 GIF/PNG를 사용하면 사각형 틀 없이 캐릭터만 둥둥 떠 있는 것처럼 보이게 만들 수 있습니다.

#### 3-2. Edit Mode (위치·크기 조절)

- **Edit Mode** 토글을 켜면 오버레이 위에 파란 테두리 상자가 나타나고, 우측 하단에 체크(✓)/취소(✕) 버튼이 뜹니다.
- **위치 이동**: 테두리 상자 안쪽 아무 곳이나 마우스 왼쪽 버튼으로 눌러 드래그하면 오버레이 전체를 원하는 위치로 옮길 수 있습니다.
- **크기 조절**: 현재 버전에서는 오버레이를 직접 드래그해서 크기를 늘리는 기능은 없고, 아래의 **X / Y / Width / Height 입력란**에 숫자를 직접 입력해서 정확한 위치와 크기를 지정하는 방식입니다. 값을 입력하면 오버레이에 실시간으로 반영됩니다.
  - X, Y: 화면 좌상단 기준 오버레이의 좌표(픽셀)
  - Width, Height: 오버레이의 가로/세로 크기(픽셀, 최소 80)
- **✓ (체크) 버튼**: 지금 위치·크기를 그대로 저장하고 편집 모드를 종료합니다.
- **✕ (취소) 버튼**: 편집 모드에 들어오기 직전 상태로 되돌리고 종료합니다. (실수로 이상한 곳으로 옮겼을 때 유용합니다.)

#### 3-3. 마우스 오버 시 자동 페이드 + 클릭 통과

- 편집 모드가 아닐 때, 오버레이는 평소엔 선명하게 보이다가 **마우스 커서가 오버레이 위로 올라가면 자동으로 옅어지고(반투명) 클릭도 그 아래 창으로 그대로 통과**합니다. 마우스가 벗어나면 다시 원래대로 선명해집니다.
- 즉, 오버레이가 항상 화면 위에 떠 있어도 그 자리를 클릭하거나 그 아래 창을 조작하는 데 방해가 되지 않습니다.


### 4. 작업표시줄(트레이) 아이콘

우측 하단 트레이 영역의 ExCord 아이콘을 통해 다음과 같이 조작할 수 있습니다.

- **더블클릭**: 설정 창을 엽니다.
- **우클릭 메뉴**:
  - **Settings**: 설정 창을 엽니다.
  - **Overlay: ON/OFF**: 오버레이를 설정 창을 열지 않고 바로 켜고 끌 수 있는 빠른 토글입니다.
  - **Exit**: 프로그램을 완전히 종료합니다. (진행 중이던 음성 재생은 안전하게 정리한 뒤 종료됩니다.)

### 5. 설정 저장 방식

- 대부분의 설정은 **변경 즉시 자동 저장**됩니다. 별도의 "저장" 버튼을 누를 필요가 없습니다.
- 설정 파일은 `%AppData%\ExCord\settings.json`에 저장됩니다.

## 설치 가이드

프로그램을 처음 다뤄보는 분도 그대로 따라 하면 되도록 단계별로 정리했습니다.

### 준비물 확인

| 항목 | 필요 여부 | 비고 |
|---|---|---|
| Windows 10 (버전 2004 / 빌드 19041 이상) 또는 Windows 11 | 필수 | 그 이전 버전에서는 실행이 안 될 수 있습니다. |
| [.NET 8 데스크톱 런타임](https://dotnet.microsoft.com/download/dotnet/8.0) | 실행 시 자동 안내됨 | 실행 파일에 포함되어 있지 않은 경우, 처음 실행할 때 Windows가 설치 링크를 자동으로 띄워줍니다. 뜨면 그대로 설치하면 됩니다. |
| WebView2 런타임 | 대부분 이미 설치되어 있음 | Windows 11과 최신 Windows 10에는 기본 내장되어 있습니다. GifTalk 화면이 안 뜬다면 [여기](https://developer.microsoft.com/microsoft-edge/webview2/)서 "Evergreen Bootstrapper"를 받아 설치하세요. |
| 가상 오디오 케이블 (예: [VB-CABLE](https://vb-audio.com/Cable/)) | TTS 기능을 디스코드에서 쓰려면 필수 | 없어도 프로그램 자체는 실행되지만, 상대방에게 음성이 전달되지 않습니다. |

### 설치 및 실행 단계

1. **최신 버전 다운로드**
   👉 **[ExCord 최신 릴리즈 다운로드](https://github.com/DA0M912/ExCord/releases/latest)**
   위 링크로 들어가서 `Assets` 목록에 있는 최신 버전 설치 파일을 내려받습니다.

2. **실행**
   내려 받은 `ExCord.exe`를 더블클릭해서 실행합니다.
   - 이때 파란색 "Windows의 PC 보호" 경고(SmartScreen)가 뜰 수 있습니다. 이는 정상적인 현상이며 아래 [참고 – SmartScreen 경고] 항목을 확인하세요.
   - .NET 8 런타임이 없다면 자동으로 설치 안내 창이 뜹니다. 안내에 따라 설치 후 ExCord를 다시 실행하세요.

3. **정상 실행 확인**
   실행되면 별도의 창 없이 조용히 작업표시줄 우측 하단(숨겨진 아이콘 포함, `^` 화살표 클릭)에 ExCord 아이콘이 나타납니다.

4. **가상 오디오 케이블 설치 (TTS를 디스코드에서 쓸 경우)**
   1. [VB-CABLE](https://vb-audio.com/Cable/) 페이지에서 `VBCABLE_Driver_Pack` zip을 내려받아 압축을 풉니다.
   2. 폴더 안의 `VBCABLE_Setup_x64.exe`를 **관리자 권한으로 실행**해서 설치합니다.
   3. 설치 후 반드시 **컴퓨터를 재시작**합니다. (재시작하지 않으면 새 오디오 장치가 안 보일 수 있습니다.)
   - 가상 오디오 장치는 꼭 VB케이블이 아니어도 가능합니다.
   - 기존에 사용중이던 가상 오디오 장치로 설정해도 정상적으로 작동합니다.

5. **ExCord 첫 설정**
   1. 트레이 아이콘을 더블클릭해서 설정 창을 엽니다.
   2. `TTS` 탭에서 **Virtual Output Device**를 `가상 입력 장치`로 선택합니다.
   3. 원하는 음성을 `TTS Voice`에서 선택합니다.
   4. 원하면 `Global Hotkey`를 취향에 맞게 바꿉니다 (기본 `Ctrl+Alt+T`).
   5. 디스코드 설정 → 음성 및 비디오 → 입력 장치를 동일한 `가상 입력 장치`으로 변경합니다.
   6. 디스코드 통화 중 `Ctrl+Alt+T`(또는 지정한 핫키)를 눌러 문장을 입력하고 Enter를 눌러보면, 상대방에게 음성이 들리는지 확인할 수 있습니다.

6. **GifTalk 사용해보기**
   1. 설정 창의 `General` 탭에서 `GifTalk`를 켭니다.
   2. `GifTalk` 탭에서 원하는 GIF/이미지 주소를 입력하고 `Apply`를 누릅니다.
   3. `Edit Mode`를 켜서 원하는 위치로 드래그하고, 필요하면 Width/Height를 숫자로 조절한 뒤 ✓로 저장합니다.

7. **Windows 시작 시 자동 실행**
   `General` 탭의 `Start with Windows`를 켜면, 다음 부팅부터는 별도로 실행하지 않아도 자동으로 켜집니다.

## 참고

- **Windows SmartScreen 경고에 대해**
  ExCord는 개인 프로젝트라 마이크로소프트의 유료 코드 서명 인증서로 서명되어 있지 않습니다. 그래서 처음 실행할 때 "Windows의 PC가 보호되었습니다" 라는 파란 화면이 뜰 수 있습니다. 이는 악성코드라는 뜻이 아니라, **서명되지 않은 프로그램이라 아직 평판 데이터가 없다는 뜻**입니다. 화면에서 **"추가 정보" → "실행"** 을 누르면 정상적으로 실행됩니다. 찜찜하다면 다운로드한 파일을 백신이나 [VirusTotal](https://www.virustotal.com/)로 직접 검사해보고 실행해도 좋습니다.
- **일부 백신 프로그램의 오탐(False Positive)**: 전역 단축키 후킹과 화면 오버레이(항상 위, 클릭 통과 등)를 사용하는 프로그램 특성상, 일부 백신이 의심 행동으로 잘못 분류할 수 있습니다. 소스 코드가 공개되어 있으니 궁금하면 직접 확인해보세요.
- **왜 소리가 상대방에게 안 들리나요?**: 가장 흔한 원인은 (1) 가상 오디오 케이블 미설치, (2) ExCord의 Virtual Output Device와 디스코드의 입력 장치가 서로 다른 장치로 설정된 경우, (3) 디스코드의 "고급 음성 활동 감지" 설정이 너무 예민하거나 반대로 감도가 낮게 잡혀 있는 경우입니다.
- **테스트 환경 (제작자 PC 사양)**: 아래는 개발 중 실제로 테스트한 환경입니다. 참고용이며, 이보다 낮은 사양에서도 대부분 문제없이 동작할 것으로 예상됩니다.
  - OS: `[여기에 Windows 버전/빌드 번호 입력]`
  - CPU: `[여기에 CPU 모델 입력]`
  - RAM: `[여기에 메모리 용량 입력]`
  - GPU: `[여기에 그래픽카드 입력, WebView2 렌더링에 영향]`
  - 사용한 가상 오디오 케이블: `[여기에 사용 제품명 입력, 예: VB-CABLE]`
- **자동 업데이트 확인**: 설정 창을 열 때마다 GitHub의 최신 릴리즈를 자동으로 확인합니다. 새 버전이 있으면 설정 창 좌측 하단에 파란색으로 깜빡이는 "New version available" 문구가 나타나며, 클릭하면 릴리즈 페이지로 이동합니다. (자동으로 설치되지는 않으며, 직접 새 버전을 받아 덮어 설치해야 합니다.)
- **로그 파일**: 오류가 발생하면 `%AppData%\ExCord\` 폴더 안에 로그 파일이 남습니다. 버그를 제보할 때 함께 첨부해주시면 원인 파악에 큰 도움이 됩니다.
- **알려진 제한 사항**
  - GifTalk 오버레이는 현재 드래그로 크기를 조절할 수 없고, 숫자 입력으로만 크기를 바꿀 수 있습니다.
  - 모니터(디스플레이) 배율이 100%가 아니거나 여러 모니터를 서로 다른 배율로 쓰는 환경에서는 오버레이 위치가 미세하게 어긋날 수 있습니다.
  - 개인 프로젝트로 제작되어 상용 소프트웨어 수준의 QA를 거치지 않았습니다. 문제를 발견하시면 이슈로 남겨주세요.
