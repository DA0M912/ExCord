# ExCord v1.0.0

디스코드 소통을 더 풍부하게 만들기 위한 개인용 부가 기능 모음 프로그램의 첫 정식 릴리스입니다. 특정 기능 하나에 치우치기보다는, 디스코드를 쓰면서 아쉬웠던 부분들을 그때그때 채워 넣는 방식으로 만들어졌습니다.

## 주요 기능

### TTS (텍스트 음성 변환)
텍스트를 입력하면 음성으로 바꿔 디스코드 통화 상대에게 들려주는 기능입니다.

- **다양한 음성 엔진 지원**: Windows의 최신 OneCore 음성 엔진과 구형 SAPI5(레거시) 음성 엔진을 모두 인식합니다. 접근성 내레이터로 추가한 음성을 포함해, 컴퓨터에 설치된 거의 모든 목소리를 설정 창의 드롭다운에서 골라 쓸 수 있습니다.
- **가상 오디오 라우팅**: 합성된 음성을 마이크가 아니라 가상 오디오 케이블 장치로 출력해서, 디스코드 통화에 자연스럽게 섞여 들어가도록 처리했습니다. 출력 장치와 볼륨은 설정 창에서 직접 조절 가능합니다.
- **전역 단축키**: 다른 프로그램(게임, 디스코드 등)에 포커스가 가 있어도 지정한 단축키로 바로 입력 창을 띄울 수 있습니다.
- **언어 자동 인식**: 입력한 텍스트의 언어를 감지해서, 선호 음성이 그 언어를 지원하지 않으면 알맞은 음성으로 자동 대체합니다.

### GifTalk (반응형 캐릭터 오버레이)
[reactive.fugi.tech](https://reactive.fugi.tech/)로 만든 캐릭터를 화면 위에 항상 떠 있는 오버레이로 표시하는 기능입니다.

- **투명 오버레이**: 창 테두리 없이 캐릭터만 화면에 떠 있는 형태입니다. 평소에는 그대로 보이다가, 마우스를 캐릭터 위에 올리면 자동으로 투명해지면서 그 아래에 있는 다른 창을 클릭할 수 있게 바뀝니다.
- **편집 모드**: 편집 버튼을 누르면 캐릭터의 테두리가 나타나고, 드래그로 위치를 옮기거나 모서리를 잡아 크기를 조절할 수 있습니다. 확인을 누르면 그 자리에 고정되고, 취소를 누르면 편집을 시작하기 전 상태로 정확히 되돌아갑니다.
- **정밀 좌표 조정**: 드래그가 아니라 숫자로 정확히 맞추고 싶을 때를 위해, 설정 창에서 X/Y 좌표와 너비/높이를 직접 입력해 미세 조정할 수 있고, 위치 초기화 버튼으로 기본 위치로 되돌릴 수도 있습니다.
- **켜고 끄기**: GifTalk 탭 상단의 On/Off 토글로 필요 없을 때는 완전히 꺼둘 수 있습니다. 꺼두면 내부적으로 쓰이는 웹뷰 리소스까지 함께 해제되어 메모리를 아낍니다.

### General (기본 설정)
- **시작 앱 등록**: Windows 부팅 시 ExCord가 자동으로 함께 실행되도록 등록할 수 있습니다. 프로그램 설치 위치가 나중에 바뀌더라도, 실행될 때마다 스스로 등록된 경로를 확인해서 필요하면 자동으로 갱신합니다.
- **업데이트 확인**: 설정 창 하단에 현재 버전이 표시되고, GitHub에 새 릴리스가 올라오면 그 옆에 새 버전 알림이 깜빡입니다. 눌러서 바로 릴리스 페이지로 이동할 수 있습니다.
- **트레이 상주**: 창을 닫아도 프로그램이 종료되지 않고 트레이에 상주하며, 트레이 아이콘에서도 주요 기능을 바로 켜고 끌 수 있습니다.

## 설치 방법
1. 아래 첨부된 `ExCordSetup-1.0.0.exe`를 내려받아 실행합니다.
2. 실행에 필요한 .NET 8 Desktop Runtime과 WebView2 Runtime이 없으면 설치 과정에서 자동으로 함께 설치됩니다.
3. 설치가 끝나면 바탕화면에 생성된 바로가기로 실행하시면 됩니다.

## 요구 사항
- Windows 10/11 (64비트)

## 참고
- 설치 파일에 별도의 코드 서명이 되어 있지 않아 실행 시 Windows SmartScreen 경고가 뜰 수 있습니다. '추가 정보' → '실행'을 눌러 진행하시면 됩니다.
